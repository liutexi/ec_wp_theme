Echo 是一款简洁、专注阅读体验的博客/论坛风格 WordPress 主题。

== 特性 ==

* 响应式设计，桌面与移动端自适应
* 文章卡片式列表，支持特色图片
* 侧边栏小工具区域
* 内置搜索浮层
* 评论支持（含嵌套回复）
* 上一篇/下一篇导航
* 自定义 logo 与导航菜单
* 分页导航
* 404 页面
* 主题自定义（外观 → 自定义）：主题色、布局、页脚等

== 安装 ==

1. 将 `echo` 文件夹上传至 `wp-content/themes/` 目录。
2. 在 WordPress 后台「外观 → 主题」中启用 Echo。
3. 在「外观 → 菜单」中创建主菜单，并指定到「主菜单」位置。
4. 在「外观 → 小工具」中为「侧边栏」添加小工具。

== 常见问题 ==

= 如何设置特色图片？ =
在编辑文章时，右侧「特色图片」面板中上传图片即可，会在列表卡片顶部显示。

= 如何修改主题颜色？ =
在 `style.css` 顶部的 `:root` 变量中调整 `--echo-primary` 等颜色变量。
