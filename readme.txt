Echo 是一款简洁、专注阅读体验的博客 / 社区风格 WordPress 主题，内置用户主页、登录注册、友情链接与完整的后台设置面板。

== 特性 ==

= 界面与排版 =
* 经典 / Miuix 两套界面风格，可整体切换
* 主题色、内容宽度、侧边栏位置（左 / 右 / 无）可配置
* 文章卡片列表，支持特色图片与分类徽章
* 可选瀑布流列表：首页、分类、搜索结果多列排版，列数 2–4 可调
* 文章页阅读进度条、返回顶部、平滑滚动
* 代码块一键复制：代码块右上角「复制」按钮，支持失败降级
* 移动端适配：折叠菜单、搜索浮层、整宽布局

= 用户系统 =
* 登录 / 注册页面模板（含找回密码、重置密码）
* 个人中心「我的」页面模板：资料卡、统计、快捷入口
* 用户主页 /uid/{ID}/：公开资料、统计、最近文章与评论
* 自助编辑资料：昵称、简介、个人网站、密码
* 自定义头像上传：全站优先显示（主页 / 我的 / 评论区 / 作者信息），无头像自动生成首字母头像，Gravatar 不可达时也不会破图

= 内容与互动 =
* 评论支持嵌套回复，评论者与文章作者身份标注
* 上一篇 / 下一篇导航、分页
* 文章底部作者信息卡
* 404 页面

= 友情链接 =
* 后台表格管理：新增、删除、拖拽排序、单条启用 / 停用
* 支持分组、描述、图标（可从媒体库选择）
* 批量导入 / 导出（名称 | 网址 | 描述 | 分组 | 图标）
* 三种展示方式：短代码 [echo_links]、页面模板「友情链接」、侧边栏小工具

= 后台 =
* 「Echo 设置」顶级菜单，悬停展开 12 个分类，页面内左侧分类导航
* 分类管理、文章管理（批量调整分类 / 状态）、设置备份与导入导出
* 即时保存开关、统一风格的通知提示

== 安装 ==

1. 后台「外观 → 主题 → 上传主题」，选择 zip 安装并启用。
2. 「外观 → 菜单」创建主菜单，指定到主题的「主菜单」位置。
3. 「设置 → 固定链接」选一个非「朴素」的结构并保存（用户主页路由需要）。
4. 「外观 → 小工具」为侧边栏添加小工具（可选）。

= 建议创建的两个页面 =
* 登录 / 注册：新建页面，别名 login，模板选「登录 / 注册」
* 个人中心：新建页面，别名 my，模板选「个人中心」

用户主页不需要建页面，直接访问 /uid/1/（1 为用户 ID）。

== 常见问题 ==

= 用户主页打不开 / 404？ =
到「设置 → 固定链接」点一次「保存更改」刷新重写规则；若改过路径前缀，同样需要重新保存一次。

= 上传头像没反应？ =
头像上限默认 4096 KB。若图片过大或服务器 post_max_size 限制过低，编辑区会给出红色提示；换小图或让主机调大限制即可。

= 如何只显示某个分组的友情链接？ =
在页面或文章中使用短代码：[echo_links group="友链" cols="3"]。

= 瀑布流下文章顺序为什么是竖着的？ =
瀑布流基于 CSS 多列实现，阅读顺序按列从上到下，属于预期行为。

= 如何深度自定义样式？ =
「Echo 设置 → 我的界面」底部有「自定义 CSS」输入框，也可直接修改 style.css 中的 :root 变量。
